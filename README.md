# Daily Coach

One assignment at a time. Capture what's in your head, get given a single next thing.

A single-page web app — no build step, no server, no account. Tasks are stored in your
browser on the device you use, and the app works offline once opened. Install it by
opening the site on your phone and choosing "Add to Home Screen".

Live: https://kares82.github.io/daily-coach-app/
